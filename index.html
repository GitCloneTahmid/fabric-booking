    How it is calculated

    Consumption (kg/dzn) = Fabric width (in) × Marker length (in) × GSM × 12 ÷ 1550 ÷ 1000 ÷ Pcs in marker
    1550 sq inch = 1 sq metre. Tube fabric: width × 2.

    Net fabric (kg) = Σ (pcs of each size × kg/dzn of that size ÷ 12) + trims.

    Booking fabric (kg) = Net fabric × (1 + cutting allowance %). Use CAD consumption as the base and 1–3 % allowance.

    Yarn before sample (kg) = Booking fabric ÷ (1 − (knitting loss % + dyeing/finishing loss %) ÷ 100).

    Yarn by composition (kg) = Yarn before sample × composition % ÷ 100.
    Total yarn (kg) = all composition lines + sample / test yarn.
